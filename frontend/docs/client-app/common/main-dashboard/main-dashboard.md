# 메인 대시보드

## 기능명

매장 운영 대시보드

## 기능 설명

로그인 후 진입하는 client 앱의 기본 화면이다. 매장의 주문, 결제, 매출 현황을 요약해 보여주며, 사용자가 주요 업무 화면으로 빠르게 이동할 수 있도록 한다.

## 접근 권한

- 로그인한 client 앱 사용자는 기본적으로 접근 가능하다.
- 별도 메뉴 접근 권한 대상에서는 제외한다.
- 스태프 계정도 로그인 후 메인 대시보드에 접근할 수 있다.

## 화면 구성

- 1차 MVP 권장안은 주요 지표 요약 카드를 먼저 제공하고, 매출 차트 영역은 정산 조회의 집계 기준 확정 후 구현하는 것이다.
- 사용자가 접근 권한을 가진 주요 메뉴로 이동할 수 있는 바로가기 영역을 제공할 수 있다.
- 차트 데이터는 정산 조회의 집계 기준을 따른다.
- 대시보드는 메뉴 트리에 포함하지 않고 엔트리 페이지로 취급한다.

## 주요 지표

| 항목 | 설명 |
| --- | --- |
| 오늘 주문 수 | 당일 접수된 주문 건수 |
| 오늘 매출 | 당일 결제 완료 금액 |
| 진행 중 주문 수 | 접수 또는 조리중 상태의 주문 수 |
| 취소 주문 수 | 당일 취소된 주문 수 |
| 결제 완료 건수 | 당일 결제 완료된 주문 수 |

## 차트 기능

| 항목 | 설명 |
| --- | --- |
| 일별 매출 차트 | 선택 기간의 일자별 매출 추이 표시 |
| 결제수단별 매출 차트 | 카드, 간편결제, 현금 등 결제수단별 매출 비중 표시 |
| 주문 상태별 건수 차트 | 접수, 조리중, 서빙완료, 취소 상태별 주문 건수 표시 |

## 차트 정책

- 차트는 빠른 추세 파악을 위한 보조 기능이다.
- 정산 검증의 기준은 정산 조회의 표 데이터로 둔다.
- 메인 대시보드 차트는 정산 조회의 집계 기준이 확정된 뒤 구현한다.
- 차트 미구현 상태의 표시 방식은 스토리보드 단계에서 확정한다.
- 차트 클릭 시 관련 상세 화면으로 이동하는 기능은 추후 검토한다.
