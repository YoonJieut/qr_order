# 결제 목록 조회

## 메뉴명

`결제 관리 > 결제 현황 > 결제 목록 조회`

## 기능명

결제 목록 조회

## 기능 설명

매장에서 발생한 결제 내역을 결제수단, 결제 금액, 쿠폰 적용 내역 기준으로 조회하는 기능이다. 1차 범위에서는 결제 내역 조회와 상세 확인을 제공하며, 결제 취소/환불 처리는 추후 검토한다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.

## 화면 구성

- 상단 검색 조건 영역과 하단 결제 목록 그리드로 구성한다.
- 결제 목록은 기본적으로 최신 결제 순으로 조회한다.
- 결제 행을 선택하면 결제 상세 정보를 확인할 수 있다.
- 결제 데이터는 물리 삭제하지 않는다.

## 검색 조건

| 조건 | 설명 |
| --- | --- |
| 결제일자 | 조회 시작일/종료일 |
| 결제수단 | 카드, 간편결제, 현금 등 |
| 결제 상태 | 결제 완료, 결제 실패, 결제 취소 등 |
| 주문번호 | 연결된 주문 기준 조회 |
| 테이블 번호 | 결제가 발생한 테이블 기준 조회 |

## 그리드 주요 항목

| 항목 | 설명 |
| --- | --- |
| 결제번호 | 결제 식별 번호 |
| 주문번호 | 연결된 주문 식별 번호 |
| 결제일시 | 결제 처리 시각 |
| 테이블 번호 | 결제가 발생한 테이블 |
| 결제수단 | 카드, 간편결제, 현금 등 |
| 결제 상태 | 결제 완료, 실패, 취소 등 |
| 결제 금액 | 최종 결제 금액 |
| 쿠폰 적용 금액 | 쿠폰 또는 할인 적용 금액 |

## 결제 상태 1차 정책

- 현재 프로젝트 1차 범위에는 실제 PG 결제 승인/취소 연동이 없다.
- 결제 상태는 주문/정산 흐름에서 사용하는 DB 상태값으로 관리한다.
- 주문이 취소되면 연결된 결제 상태도 1차 기준으로 `취소` 또는 이에 준하는 DB 상태로 변경한다.
- 이 상태 변경은 외부 PG 환불을 의미하지 않는다.
- 실제 PG 결제 취소와 환불 처리는 추후 PG사 결제 승인(Mock Payment Adapter) 검토 단계에서 별도 정의한다.

## 추후 검토

- 결제 취소 및 환불 처리
- 전체 취소 후 재결제 방식 또는 부분 취소 방식 검토
- PG사 결제 승인(Mock Payment Adapter) 구현 검토
- 결제 실패 및 취소 실패 처리
- 결제 승인번호, 거래번호, 영수증 URL 표시
- 환불 권한 및 재확인 절차
- 결제 취소/환불 내역의 정산 반영 기준
