# 정산 조회

## 메뉴명

`결제 관리 > 정산 관리 > 정산 조회`

## 기능명

정산 및 매출 통계 조회

## 기능 설명

매장의 기간별 매출, 결제수단별 매출, 주문 건수, 취소 금액, 순매출을 표 중심으로 조회하는 기능이다. 정산 조회의 표 데이터는 메인 대시보드 차트의 기준 데이터로 사용한다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.

## 화면 구성

- 상단 검색 조건 영역과 하단 정산 집계 표로 구성한다.
- 조회 기간 기준으로 매출/취소/순매출을 집계한다.
- 결제수단별 합계와 일자별 합계를 확인할 수 있다.
- 차트 기반 시각화는 메인 대시보드에서 제공한다.

## 검색 조건

| 조건 | 설명 |
| --- | --- |
| 정산 기간 | 조회 시작일/종료일 |
| 결제수단 | 카드, 간편결제, 현금 등 |
| 집계 단위 | 일별, 월별 등 |

## 집계 주요 항목

| 항목 | 설명 |
| --- | --- |
| 주문 건수 | 해당 기간의 주문 수 |
| 결제 건수 | 결제 완료 건수 |
| 총 결제 금액 | 결제 완료 금액 합계 |
| 취소 금액 | 취소 또는 환불 금액 합계 |
| 할인 금액 | 쿠폰 등 할인 적용 금액 합계 |
| 순매출 | 총 결제 금액에서 취소/할인 등을 반영한 금액 |

## 구현 우선순위

- 1차 구현은 정산 조회의 표 중심 집계를 우선한다.
- 표 중심 정산 조회는 매출/취소/순매출 숫자 검증의 기준 데이터로 사용한다.
- 메인 대시보드 차트는 정산 조회의 집계 기준이 확정된 뒤 구현한다.
- 차트는 빠른 추세 파악을 위한 보조 기능이며, 정산 검증의 기준은 표 데이터로 둔다.
