# 실시간 주문 조회

## 메뉴명

`주문 관리 > 주문 현황 > 실시간 주문 조회`

## 기능명

실시간 주문 조회 및 주문 상태 변경

## 기능 설명

고객이 QR 주문 화면에서 접수한 주문을 실시간으로 조회하고 처리 상태를 변경하는 기능이다. 매장 사용자는 신규 주문을 확인하고 주문 상세 내역을 확인할 수 있다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.

## 화면 구성

- 주문 현황은 상태별 보드형 화면으로 제공한다.
- 화면을 주문 상태 기준으로 4개 컬럼으로 나눈다.
- 기본 컬럼은 `접수`, `조리중`, `서빙완료`, `취소`로 구성한다.
- 각 컬럼 안에는 해당 상태의 주문을 카드 형태로 표시한다.
- 주문 카드를 선택하면 주문 상세 정보를 확인할 수 있다.
- 실시간 갱신 방식은 API/기술 검토 후 확정한다.

## 주문 카드 주요 정보

| 항목 | 설명 |
| --- | --- |
| 테이블 번호 | 주문이 발생한 테이블 |
| 주문번호 | 주문 식별 번호 |
| 주문 시각 | 주문 접수 시각 |
| 메뉴 요약 | 대표 메뉴명과 총 수량 |
| 주문 금액 | 주문 총 금액 |
| 결제 상태 | 결제 전, 결제 완료 등 |

## 상태 변경 방식

- 주문 카드에는 현재 상태에서 다음 상태로 변경하는 주요 버튼을 제공한다.
- `접수` 주문은 `조리중으로 변경` 또는 `취소`할 수 있다.
- `조리중` 주문은 `서빙완료로 변경` 또는 `취소`할 수 있다.
- `서빙완료` 주문은 기본적으로 상태 변경을 제공하지 않는다.
- `취소` 주문은 상태 변경을 제공하지 않는다.
- 상태 변경 전 ConfirmModal로 재확인한다.
- 1차 주문 취소는 결제 전/결제 후 주문 모두 허용한다.
- 1차 범위에서는 실제 PG 결제 취소나 환불 API를 호출하지 않고, 주문/결제 관련 DB 상태 변경으로 취소를 관리한다.
- 결제 완료 주문을 취소한 경우 정산 조회에서 취소 금액과 순매출 계산에 반영한다.

## 상태 변경 예시

| 현재 상태 | 변경 가능 상태 |
| --- | --- |
| 접수 | 조리중, 취소 |
| 조리중 | 서빙완료, 취소 |
| 서빙완료 | 원칙적으로 변경 불가 |
| 취소 | 변경 불가 |

## 추후 검토

- 상태 컬럼 크기 조정
- 상태 컬럼 접기/펼치기
- 주문 카드 드래그 앤 드롭으로 상태 변경
- 신규 주문 알림음 또는 화면 강조
- 주방용 큰 화면 모드
- 실제 PG 환불 또는 부분 취소 연동
