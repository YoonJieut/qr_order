# 주문 이력 조회

## 메뉴명

`주문 관리 > 주문 이력 > 주문 이력 조회`

## 기능명

주문 이력 조회

## 기능 설명

매장에서 발생한 과거 주문 내역을 조회하는 기능이다. 고객 컴플레인 대응, 주문 상세 확인, 결제 상태 확인, 운영 내역 확인을 주 목적으로 사용한다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.

## 화면 구성

- 상단 검색 조건 영역과 하단 주문 이력 그리드로 구성한다.
- 주문 이력은 기본적으로 최신 주문 순으로 조회한다.
- 주문 행을 선택하면 주문 상세 내역을 확인할 수 있다.
- 주문 상세에는 주문 메뉴, 옵션, 수량, 금액, 주문 상태, 결제 상태, 주문/결제 시각을 표시한다.
- 주문 이력 화면에서는 주문 상태 변경을 제공하지 않는다.
- 주문 이력 데이터는 물리 삭제하지 않는다.

## 검색 조건

| 조건 | 설명 |
| --- | --- |
| 주문일자 | 조회 시작일/종료일 |
| 테이블 번호 | 특정 테이블 주문 조회 |
| 주문 상태 | 접수, 조리중, 서빙완료, 취소 |
| 결제 상태 | 결제 전, 결제 완료 등 |
| 주문번호 | 고객 문의 대응 시 특정 주문을 직접 조회 |

## 그리드 주요 항목

| 항목 | 설명 |
| --- | --- |
| 주문번호 | 주문 식별 번호 |
| 주문일시 | 주문 접수 시각 |
| 테이블 번호 | 주문이 발생한 테이블 |
| 주문 메뉴 요약 | 대표 메뉴명 및 총 수량 |
| 주문 상태 | 주문 처리 상태 |
| 결제 상태 | 결제 처리 상태 |
| 주문 금액 | 주문 총 금액 |

## 주문 상세 주요 항목

| 항목 | 설명 |
| --- | --- |
| 주문 기본 정보 | 주문번호, 주문일시, 테이블 번호 |
| 주문 메뉴 | 메뉴명, 옵션, 수량, 단가, 금액 |
| 주문 금액 | 상품 금액, 할인 금액, 최종 금액 |
| 상태 정보 | 주문 상태, 결제 상태 |
| 결제 정보 | 결제수단, 결제일시, 결제 승인번호 등 |
