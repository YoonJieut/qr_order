# 테이블 관리

## 메뉴명

`매장 관리 > 테이블 정보 관리 > 테이블 관리`

## 기능명

테이블 정보 등록 및 관리

## 기능 설명

매장 내 테이블 번호와 좌석 수를 등록, 수정하고, 더 이상 사용하지 않는 테이블을 비활성화하는 기능이다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.
- 메뉴 접근 권한이 있는 사용자는 테이블 정보를 등록, 수정, 비활성화할 수 있다.

## 화면 구성

- 단순 그리드 형태로 제공한다.
- 행 추가를 통해 신규 테이블을 등록한다.
- 기존 행에서 테이블 번호와 좌석 수를 수정할 수 있다.
- 테이블을 더 이상 사용하지 않는 경우 사용 여부를 비활성화한다.
- 물리 삭제는 제공하지 않는다.
- 테이블 배치 GUI는 1차 범위에서 제외한다.

## 주요 항목

| 항목 | 설명 |
| --- | --- |
| 테이블 번호 | 고객 주문 화면과 QR코드에 표시될 테이블 식별값 |
| 좌석 수 | 해당 테이블의 기본 좌석 수 |
| 사용 여부 | 해당 테이블을 주문/QR 대상으로 사용할지 여부 |

## 저장/비활성화 정책

- 저장 시 ConfirmModal로 재확인한다.
- 사용 여부를 비활성화할 때 ConfirmModal로 재확인한다.
- 저장 성공 시 AlertModal을 표시하고 목록을 다시 조회한다.
- 저장 실패 시 ErrorModal을 표시한다.

## 비활성화 확인 문구 예시

> 이 테이블을 사용하지 않도록 변경하시겠습니까? 비활성화된 테이블은 고객 주문에서 사용할 수 없습니다.
