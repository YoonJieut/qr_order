# QR코드 관리

## 메뉴명

`매장 관리 > 테이블 정보 관리 > QR코드 관리`

## 기능명

테이블별 QR코드 생성 및 관리

## 기능 설명

등록된 테이블별 QR코드를 생성, 재발급, 출력하는 기능이다. QR코드는 고객이 테이블에서 주문 화면에 접근하기 위한 진입 수단으로 사용된다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.
- 메뉴 접근 권한이 있는 사용자는 QR코드 생성, 재발급, 출력을 수행할 수 있다.

## 화면 구성

- 그리드 형태로 제공한다.
- 등록된 테이블 목록을 기준으로 QR코드 생성 상태를 표시한다.
- 테이블별 QR코드를 생성할 수 있다.
- 기존 QR코드를 재발급할 수 있다.
- 생성된 QR코드를 출력할 수 있다.
- 사용 여부가 비활성화된 테이블은 기본 생성 대상에서 제외한다.

## 주요 항목

| 항목 | 설명 |
| --- | --- |
| 테이블 번호 | QR코드가 연결될 테이블 |
| 좌석 수 | 테이블 참고 정보 |
| QR 생성 여부 | 해당 테이블의 QR코드 생성 상태 |
| QR 생성 일시 | 마지막 생성 또는 재발급 일시 |
| 사용 여부 | 테이블 사용 여부 |

## QR 생성 정책

- QR코드는 활성 상태의 테이블을 기준으로 생성한다.
- QR코드가 없는 테이블은 신규 생성할 수 있다.
- 이미 QR코드가 있는 테이블은 재발급할 수 있다.

## QR 재발급 정책

- QR코드 재발급 시 기존 QR코드는 즉시 무효화한다.
- 기존 QR코드로 접근한 고객은 주문 화면에 진입할 수 없다.
- 재발급 후에는 새 QR코드를 출력하여 매장 내 기존 QR을 교체해야 한다.
- 재발급 실행 전 ConfirmModal로 위험성을 안내하고 재확인한다.

## 재발급 확인 문구 예시

> QR코드를 재발급하면 기존 QR코드는 즉시 사용할 수 없습니다. 매장에 부착된 QR코드를 새 QR코드로 교체해야 합니다. 계속 진행하시겠습니까?

## 출력 정책

- 생성된 QR코드는 테이블별로 출력할 수 있다.
- 복수 테이블 선택 후 일괄 출력 기능은 1차 또는 추후 범위로 검토한다.
