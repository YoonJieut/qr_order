# 매장 기본 정보

## 메뉴명

`매장 관리 > 매장 정보 관리 > 매장 기본 정보`

## 기능명

매장 기본 정보 조회 및 수정

## 기능 설명

현재 매장의 상호명, 주소, 연락처, 영업시간 등 기본 정보를 조회하고 수정하는 기능이다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.
- 해당 메뉴 접근 권한이 있는 사용자는 매장 기본 정보를 수정할 수 있다.

## 화면 구성

- 그리드가 아닌 단일 폼 형태로 제공한다.
- 신규 행 추가/삭제는 제공하지 않는다.
- 로그인 사용자의 소속 매장 정보를 기준으로 한 건만 조회한다.

## 저장 정책

- 저장 버튼 클릭 시 ConfirmModal로 변경 여부를 재확인한다.
- 사용자가 확인하면 수정 내용을 저장한다.
- 저장 성공 시 AlertModal을 표시하고 최신 매장 정보를 다시 조회한다.
- 저장 실패 시 ErrorModal을 표시한다.

## 재확인 문구 예시

> 매장 기본 정보를 수정하시겠습니까? 변경된 정보는 고객 주문 화면에 반영될 수 있습니다.
