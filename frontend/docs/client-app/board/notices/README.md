# 공지사항 조회

## 메뉴명

`게시판 > 공지사항 > 공지사항 조회`

## 기능명

공지사항 조회

## 기능 설명

시스템 관리자가 등록한 서비스 공지사항을 client 앱 사용자가 조회하는 기능이다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.

## 화면 구성

- 공지사항 목록과 상세 조회 화면으로 구성한다.
- 목록에서 제목, 등록일, 중요 여부, 조회 여부를 확인할 수 있다.
- 공지사항을 선택하면 상세 내용을 확인할 수 있다.
- client 앱에서는 공지사항 등록, 수정, 삭제를 제공하지 않는다.

## 검색 조건

| 조건 | 설명 |
| --- | --- |
| 제목 | 공지사항 제목 기준 검색 |
| 등록일자 | 공지 등록 시작일/종료일 |
| 중요 여부 | 중요 공지 여부 |

## 목록 주요 항목

| 항목 | 설명 |
| --- | --- |
| 제목 | 공지사항 제목 |
| 중요 여부 | 중요 공지 표시 여부 |
| 등록일 | 공지 등록일 |
| 조회 여부 | 사용자가 해당 공지를 확인했는지 여부 |

## 상세 주요 항목

| 항목 | 설명 |
| --- | --- |
| 제목 | 공지사항 제목 |
| 내용 | 공지사항 본문 |
| 첨부파일 | 공지에 첨부된 파일이 있는 경우 표시 |
| 등록일 | 공지 등록일 |

## 공지사항 조회 여부 표시

- 사용자가 공지사항 상세를 열면 해당 공지를 조회한 것으로 처리한다.
- 조회한 공지는 목록에서 제목 또는 행 텍스트 색상을 연하게 표시한다.
- 미조회 공지는 기본 텍스트 색상 또는 강조 표시로 구분한다.
- 중요 공지는 조회 여부와 별개로 중요 표시를 유지한다.
- 사용자별 공지 조회 이력 저장 방식은 API 명세 단계에서 확정한다.
