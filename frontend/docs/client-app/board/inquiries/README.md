# 문의사항 관리

## 메뉴명

`게시판 > 문의사항 > 문의사항 관리`

## 기능명

문의사항 등록 및 조회

## 기능 설명

client 앱 사용자가 서비스 이용 중 발생한 문의사항을 등록하고, 등록한 문의 및 답변을 조회하는 기능이다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.
- 문의사항 메뉴 접근 권한이 있는 사용자는 문의 등록과 조회를 수행할 수 있다.
- 추후 필요 시 버튼 비활성화 및 역할/권한 조회를 통해 등록 권한을 별도로 제한할 수 있다.

## 화면 구성

- 상단 검색 조건 영역과 하단 문의사항 목록 그리드로 구성한다.
- 문의사항 등록은 모달 또는 별도 등록 화면에서 진행한다.
- 문의사항 행을 선택하면 문의 상세 및 답변 내용을 확인할 수 있다.
- 문의사항 데이터는 물리 삭제하지 않는다.

## 검색 조건

| 조건 | 설명 |
| --- | --- |
| 등록일자 | 문의 등록 시작일/종료일 |
| 처리 상태 | 접수, 답변 완료 등 |
| 제목 | 문의 제목 기준 검색 |

## 목록 주요 항목

| 항목 | 설명 |
| --- | --- |
| 제목 | 문의사항 제목 |
| 작성자 | 문의 등록 사용자 |
| 등록일 | 문의 등록일 |
| 처리 상태 | 접수, 답변 완료 등 |
| 답변일 | 답변이 등록된 일시 |

## 등록 주요 항목

| 항목 | 필수 | 설명 |
| --- | ---: | --- |
| 제목 | Y | 문의 제목 |
| 내용 | Y | 문의 내용 |
| 첨부파일 | N | 문의 관련 파일 첨부 |

## 답변 정책

- 답변은 시스템 관리자 또는 운영 관리자가 등록한다.
- client 앱에서는 답변 내용을 조회만 할 수 있다.
- 답변 완료 후 문의 작성자는 목록에서 처리 상태를 확인할 수 있다.
