# 옵션 관리

## 메뉴명

`메뉴 관리 > 메뉴 정보 관리 > 옵션 관리`

## 기능명

메뉴별 옵션 그룹 및 옵션 항목 관리

## 기능 설명

메뉴별로 선택 가능한 옵션 그룹과 옵션 항목을 등록, 수정, 비활성화하는 기능이다. 옵션은 고객 주문 화면에서 메뉴 선택 시 추가 선택값으로 사용된다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.
- 메뉴 접근 권한이 있는 사용자는 옵션 그룹과 옵션 항목을 등록, 수정, 비활성화할 수 있다.

## 화면 구성

- 왼쪽 영역에는 메뉴 목록을 표시한다.
- 오른쪽 상단에는 선택한 메뉴의 옵션 그룹 목록을 표시한다.
- 오른쪽 하단에는 선택한 옵션 그룹의 옵션 항목 목록을 표시한다.
- 메뉴를 선택하면 옵션 그룹 목록을 갱신한다.
- 옵션 그룹을 선택하면 옵션 항목 목록을 갱신한다.
- 옵션은 메뉴별로 직접 설정한다.
- 공통 옵션 그룹을 만들어 여러 메뉴에 재사용하는 기능은 1차 범위에서 제외한다.

## 옵션 그룹 주요 항목

| 항목 | 설명 |
| --- | --- |
| 옵션 그룹명 | 사이즈 선택, 맵기 선택, 추가 토핑 등 옵션 묶음 이름 |
| 필수 선택 여부 | 고객이 반드시 선택해야 하는 옵션 그룹인지 여부 |
| 다중 선택 여부 | 옵션 항목을 여러 개 선택할 수 있는지 여부 |
| 최소 선택 수 | 선택해야 하는 최소 항목 수 |
| 최대 선택 수 | 선택 가능한 최대 항목 수 |
| 정렬 순서 | 고객 주문 화면에 표시될 순서 |
| 사용 여부 | 옵션 그룹 사용 여부 |

## 옵션 항목 주요 항목

| 항목 | 설명 |
| --- | --- |
| 옵션명 | 고객에게 표시될 옵션 항목 이름 |
| 추가 금액 | 해당 옵션 선택 시 추가되는 금액 |
| 기본 선택 여부 | 고객 주문 화면에서 기본으로 선택될 항목 여부 |
| 정렬 순서 | 옵션 그룹 내 표시 순서 |
| 사용 여부 | 옵션 항목 사용 여부 |

## 옵션 설정 정책

- 옵션은 `옵션 그룹`과 `옵션 항목`으로 구분한다.
- 옵션 그룹에는 필수 선택 여부, 다중 선택 여부, 최소/최대 선택 수를 설정한다.
- 옵션 항목에는 옵션명, 추가 금액, 기본 선택 여부를 설정한다.
- 기본 선택 항목은 해당 옵션 그룹 안에서 설정한다.

## 옵션 검증 정책

- 필수 선택 옵션 그룹은 최소 1개 이상의 활성 옵션 항목이 있어야 한다.
- 기본 선택 항목은 활성 옵션 항목 중에서만 지정할 수 있다.
- 단일 선택 옵션 그룹은 기본 선택 항목을 최대 1개만 지정할 수 있다.
- 다중 선택 옵션 그룹은 기본 선택 항목을 여러 개 지정할 수 있다.
- 기본 선택 항목 수는 최대 선택 수를 초과할 수 없다.
