# 메뉴 관리

## 메뉴명

`메뉴 관리 > 메뉴 정보 관리 > 메뉴 관리`

## 기능명

메뉴 카테고리 및 메뉴 정보 관리

## 기능 설명

매장에서 판매하는 메뉴 카테고리와 메뉴 기본 정보를 등록, 수정, 비활성화하는 기능이다. 메뉴별 대표 이미지를 등록하거나 수정할 수 있다.

## 접근 권한

- client-admin은 접근 가능하다.
- 스태프 계정은 client-admin이 해당 메뉴 접근 권한을 부여한 경우 접근 가능하다.
- 메뉴 접근 권한이 있는 사용자는 카테고리 및 메뉴 정보를 등록, 수정, 비활성화할 수 있다.

## 화면 구성

- 한 화면을 좌/우 세로 그리드로 분할한다.
- 왼쪽 그리드: 메뉴 카테고리 목록
- 오른쪽 그리드: 선택한 카테고리에 속한 메뉴 목록
- 왼쪽 카테고리를 선택하면 오른쪽 메뉴 목록을 갱신한다.
- 메뉴 추가/수정은 모달에서 진행한다.
- 메뉴 이미지 등록/수정은 메뉴 추가/수정 모달 안에서 처리한다.
- 메뉴 목록 행에 옵션 관리 진입 버튼을 제공할 수 있다.
- 카테고리와 메뉴 모두 물리 삭제하지 않고 사용 여부 비활성화로 처리한다.

## 카테고리 주요 항목

| 항목 | 설명 |
| --- | --- |
| 카테고리명 | 메뉴를 묶는 분류명 |
| 정렬 순서 | 고객 주문 화면에 노출될 순서 |
| 사용 여부 | 해당 카테고리 노출 여부 |

## 메뉴 주요 항목

| 항목 | 설명 |
| --- | --- |
| 메뉴명 | 고객 주문 화면에 표시될 메뉴 이름 |
| 메뉴 이미지 | 고객 주문 화면에 표시될 메뉴 대표 이미지 |
| 가격 | 메뉴 기본 판매 가격 |
| 설명 | 메뉴 설명 |
| 정렬 순서 | 카테고리 내 노출 순서 |
| 판매 상태 | 판매중, 품절, 숨김 등 메뉴 노출/판매 상태 |
| 사용 여부 | 메뉴 데이터 사용 여부 |

## 메뉴 이미지 정책

- 메뉴별 대표 이미지를 등록, 수정할 수 있다.
- 이미지 미등록 시 고객 주문 화면에는 기본 이미지 또는 이미지 없는 형태로 표시한다.
- 기존 이미지를 교체해도 과거 주문 이력의 메뉴 정보는 보존한다.
- 이미지 파일 형식, 용량 제한, 권장 비율은 스토리보드 또는 API 명세 단계에서 확정한다.

## 비활성화 정책

- 카테고리를 비활성화하면 고객 주문 화면에서 해당 카테고리와 하위 메뉴를 노출하지 않는다.
- 메뉴를 비활성화하면 고객 주문 화면에서 해당 메뉴를 노출하지 않는다.
- 비활성화된 데이터는 운영 이력 보존을 위해 물리 삭제하지 않는다.

## 메뉴 관리와 옵션 관리 분리 정책

- 메뉴 기본 정보와 옵션 설정은 별도 메뉴로 분리한다.
- 메뉴 관리는 카테고리, 메뉴명, 가격, 설명, 이미지, 판매 상태, 사용 여부에 집중한다.
- 옵션 관리는 메뉴별 옵션 그룹과 옵션 항목 설정에 집중한다.
- 메뉴 관리 화면에서는 각 메뉴 행에 `옵션 관리` 진입 버튼을 제공할 수 있다.
- `옵션 관리` 버튼 클릭 시 해당 메뉴 기준으로 옵션 관리 화면에 진입한다.
